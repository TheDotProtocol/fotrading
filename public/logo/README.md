# Logo Folder

Please place your logo files here:

- `logo.png` or `logo.svg` - Main logo (recommended: 200x50px or similar)
- `logo-icon.png` or `logo-icon.svg` - Icon version (recommended: 64x64px or similar)
- `favicon.ico` - Browser favicon (recommended: 32x32px or 16x16px)

Supported formats: PNG, SVG, ICO

After adding your logo files, the app will automatically use them in:
- Navbar
- Footer
- Browser tab (favicon)
- Admin portal
